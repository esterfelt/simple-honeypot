# simple-honeypot

Простой honeypot, который собирает информацию об ip-адресе и потенциальном инжекте в запросе злоумышленника.

## Запуск
pip install flask
python app.py

## Логи
- Дата - ip-адрес - потенциальный инжект (True/False) - логин - пароль

## Библиотеки
Flask

## ВАЖНО
Проект сделан исключительно в ознакомительных целях. Запускать только локально или в лабораторной среде
